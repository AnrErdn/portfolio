## THE PROBLEM

Apple's productivity apps — Notes, Reminders, Calendar — work well in isolation but feel disconnected as a suite. No unified flow between them. Switching context costs attention. The question I explored: what would it look like if they were designed as one cohesive system?

## THE SOLUTION

A concept redesign exploring a unified productivity layer. Shared design language across all three apps, a cross-app command palette, and a focus mode that collapses everything into a single-task view. Every decision balanced Apple's existing conventions with the hypothesis that more integration means less friction.

## Process

**01 — Deconstruction.** I used Apple's apps for two weeks while documenting every friction point. Where did I switch apps unnecessarily? Where did I lose context? The answer was almost always at task boundaries — finishing a note and needing to create a reminder from it.

**02 — Design system.** I built a shared component library spanning all three apps: tokens, type scale, iconography. The constraint: nothing could feel wrong inside an Apple product. Every component had to pass a plausibility test against existing HIG patterns.

**03 — Prototyping.** I focused on two flows — note to reminder handoff, and calendar to focus mode — and built high-fidelity prototypes for both. These were the moments where integration had the most value and the most design risk.

## Outcome

Personal concept — design exploration. Not affiliated with Apple. Built as a portfolio exercise to demonstrate systems thinking and the ability to work within an established design language while extending it.

## What I'd do differently

I underscoped the command palette. It became the most interesting part of the concept but I ran out of time to develop it properly. It deserves its own exploration — the interaction model alone is worth a separate project.
