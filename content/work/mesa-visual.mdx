## THE PROBLEM

Mongolian esports events consistently looked under-produced compared to the quality of the competition. MESA events — including the Mongolian Valorant Tournament 2025 — needed visual assets that matched the energy and stakes of the game being played.

## THE SOLUTION

A full visual asset suite for the tournament: key art, player card templates, social media graphics, stage graphics, and sticker designs. Built a visual system that could generate consistent assets across formats without requiring a rebuild for each piece.

## Process

**01 — Direction.** I researched the visual language of top-tier Valorant tournaments (VCT, regional leagues) and identified what made them feel premium: intentional typography, restrained color, and photography that made players look like athletes. I worked backwards from that standard.

**02 — System design.** Rather than designing individual pieces, I built a system: a grid structure, a type hierarchy, and a color system that all assets shared. This made the workflow scalable — adding a new player card or format didn't require starting from scratch.

**03 — Execution.** Delivered key art, a landing page concept for Nomadic Masters Spring 2025, player cards for the Mongolian Valorant Tournament 2025, and social graphics for match announcements. All delivered before tournament launch.

## Outcome

Assets delivered for Mongolian Valorant Tournament 2025 and Nomadic Masters Spring 2025. The event ran. Sticker designs also produced for merchandise.

## What I'd do differently

I'd establish a shared file structure with the production team earlier. Several assets had to be adapted at the last minute because the dimensions I delivered didn't match the screen specs on-site. Better spec documentation upfront would have prevented that.
